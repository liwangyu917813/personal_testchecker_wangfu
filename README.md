# 考试个人看板 · 使用说明

一个**单文件、离线可用**的考试查询工具：提交监考表 Excel + 输入姓名，即可生成个人考试看板（时间 / 科目 / 地点 / 星期 / 时长 / 倒计时），支持打印、存为 PDF、复制文本、**导出 .ics 日历**（可导入手机/电脑日历，自动提前 30 分钟提醒）。

## 怎么用（发给大家）

1. 双击打开 **`考试个人看板.html`**（电脑或手机浏览器均可，无需安装任何软件、无需联网）
2. 把最新版的**期中考试监考表 `.xlsx`** 拖进页面（或点击选择文件）
3. 输入姓名，点「查询我的考试」
4. 看板立即生成；点「打印 / 存为 PDF」可以保存或贴在桌上

> 文件只在本地浏览器解析，不会上传到任何服务器。
> 只支持 `.xlsx`；老版 `.xls` 请先在 Excel / WPS 中另存为 `.xlsx`。

## 更新流程（监考表出新版时）

**工具本身不用改**——让大家重新提交最新版 `.xlsx` 即可。

只有当监考表**格式大改**（列名、结构变化）时才需要维护者介入：

```bash
cd 源码与测试/src
# 修改 core.js 或 app.js 后：
node build.js        # 重新打包 → 生成 ../考试个人看板.html
node test_core.js    # 跑核心测试
node test_e2e.js     # 跑端到端测试
```

## 智能容错一览（v3）

- **日期**：`11.9`、`11月10日`、`2026-11-10`、`11/10`、`1109`（MMDD 数字/字符串）、Excel 日期序列号、合并单元格跨行日期均支持；
  **v3 新增**：`周三11.9`（星期前缀）、`(11.9)`（括号包裹）、`Nov 9` / `9-Nov` / `November 9, 2026`（英文月名）、`十一月九日` / `11月初三`（中文数字）、`8:00 11.9`（带时间前缀）；
  数值 `11.1` 会按「表中日期先后顺序」自动恢复为 11月1日 或 11月10日（Excel 会把 11.10 的尾零吞掉）；
  **v4 新增 · 考试日期连贯性智能修正**：考试日期通常连续几天（11.9/11.10/11.11），若某日期脱离连续段
  （如出现 11.1），且符合「尾零丢失」特征（11.1×10=11.10 恰落在连续段范围内）→ 自动修正为 11.10，
  顶部清单与考试卡片双重标记；无法确定目标时**保留原值并醒目警告**，绝不猜测；
  该逻辑**对任意月份通用**（3月、5月连排考试同样有效），跨年连续段（12月→1月）也支持；
  **全年支持**：8-12 月按当年、1-7 月按学期跨年（2026-2027 学年的 3.5 → 2027年3月5日），春秋季混排也能正确判年
- **时间**：`800-930`、`8:30-9:30`、全角字符、波浪线、`至/到` 连接均可识别；
  **v3 新增**：`8时00分-9时30分`（中文时分）、`8时`、`下午2:00-4:00` / `下午2点-4点`（12 小时制自动 +12）、`8am-9:30am`（AM/PM）、`上午8:00`；
  单一开始时刻 `800` 也能识别（无结束时间会提示）；识别失败保留原文并警告，不丢行
- **表头**：中英文表头均认识；**表头可出现在前 30 行的任意位置**（前面有标题、说明、多级表头都不怕）；多 Sheet 自动选数据表；
  列名同义扩展（开始时间/考试科目/教室/名单/Candidate 等）；个别列名缺失按标准列序推断并提示
- **学生名单**：忽略空格（含全角）、大小写、间隔号；无精确命中时给出候选名单；
  **v3 新增**：同一格多个姓名自动拆分（顿号、逗号、分号、换行、空格分隔均可）；
  **同名智能检测**：出现真同名（不同班级的非合考场行）或同日时间重叠时会提示「存在同名，请核对班级」，合考场（年级如 `10,12`）不会误报
- **考场**：考场列缺失时自动从科目文本提取括号内的考场号（如 `数学(3103)` → 考场 3103，科目显示为「数学」）
- **解析透明**：日期自动修正（尾零恢复）会在页面上列出「原值 → 修正值」清单，可人工复核
- **其他**：重复行自动去重；上次查询的姓名自动记住（仅存本机浏览器）；看板支持一键「复制为文本」分享；考试进行中会标出「● 进行中」（呼吸脉冲动画）并显示预计剩余分钟
- **动效（v3）**：卡片依次入场、悬浮上浮、今天日期行高亮、倒计时进度条（今天/临近/进行中三种状态色）；系统开启「减弱动态效果」时自动关闭所有动画
- 任何无法识别的内容都会**明确提示**，绝不静默给错结果

## 注意

修正逻辑依赖「日期在表中按时间先后排列」这一惯例。如果某天学校的表日期块本身乱序，页面会显示警告要求人工核对。
