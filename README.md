# 期中考试个人看板

一个**单文件、离线可用**的考试查询工具：输入姓名，立即生成个人考试看板——每场考试的日期、星期、时间、地点、时长、倒计时一目了然，还支持打印 / 存 PDF、复制文本、导出手机日历（自动提前 30 分钟提醒）。

> 仓库根目录的 `index.html` 就是**在线版**：打开即查，无需拖文件，数据由管理员统一更新。
> 单文件版（双击 HTML + 拖入监考表，完全离线）见项目内 `使用说明.md`。

---

## 一、在线版使用说明

### 1. 查询步骤

1. 打开在线页面：**https://liwangyu917813.github.io/personal_testchecker_wangfu/**
2. 页面会自动加载最新考试数据（无需任何操作）
3. 输入姓名（示例「灭建国」的位置换成你的名字），点「查询我的考试」
4. 看板立即生成；点「打印 / 存为 PDF」可以保存或贴在桌上

> 数据只在你的浏览器里解析，姓名不会被记录或上传。
> 若自动加载失败（网络原因），页面会自动展示「手动选择本地文件」备用入口，拖入监考表 `.xlsx` 即可。

### 2. 功能一览

| 功能 | 说明 |
| --- | --- |
| 部分匹配 | 只输入姓氏或名字一部分，列出候选名单供选择 |
| 同名提示 | 检测到同名同学时提示「请核对班级」，每张卡片有年级 / 班级 / 考场可分辨 |
| 倒计时 | 距下一场考试还有几天 / 几小时 / 几分钟，带进度条 |
| 进行中标记 | 正在进行的考试显示「● 进行中」呼吸标记和预计剩余分钟 |
| 打印 / PDF | A4 排版，适合贴在桌上 |
| 复制文本 | 一键复制全部考试安排，发给同学或家人 |
| 导出日历 | 下载 .ics 文件，导入手机日历，每场考试自动提前 30 分钟提醒 |
| 记住姓名 | 上次查询的姓名自动记住（仅保存在本机浏览器） |

### 3. 常见问题

| 问题 | 说明 |
| --- | --- |
| 查不到自己？ | 先试试只输入名字的一部分。若候选名单里也没有，说明监考表里没有这个名字（可能有空格或写法差异，请找管理员核对原表） |
| 提示「存在同名」？ | 看卡片上的年级 / 班级 / 考场，确认是哪一位的考试 |
| 更新后看到旧结果？ | 浏览器缓存所致，按 **Ctrl+F5**（Mac：Cmd+Shift+R）强制刷新 |
| 顶部出现黄色警告？ | 解析器发现原表某处格式异常（如不存在的日期 `2.30`）。看板的承诺是**绝不静默猜一个错的结果**——警告写明了行号和原因，请按提示人工核对 |
| 卡片上出现「日期已修正」标记？ | Excel 会把 `11.10` 的尾零吞成 `11.1`，看板按考试日期连续规律自动恢复，并在顶部列出「原值 → 修正值」清单供复核 |
| 隐私安全吗？ | 全部计算在浏览器本地完成；仓库为 Public 时任何人可下载 exam.xlsx，如需保密请改用私有部署 |

### 4. 准确性保障

看板对看不懂的内容**明确警告、绝不猜错**。背后有 **178 项自动化测试**守护：真实表格回归、坏格式对抗、在线模式专项、400 回合模糊输入、真实表随机破坏，以及 12 个月 × 随机错误注入的全年冗余测试。

## 三、仓库结构


## 四、管理员手册

### 每学期更新（运营者唯一要做的动作）

1. 打开仓库 → `data/` 目录
2. 把新的监考表**改名为 `exam.xlsx`**，覆盖上传（Add file → Upload files，拖入后 Commit）
3. 访客下次打开页面就是新数据（Ctrl+F5 可强制刷新缓存）

> ⚠️ 五个文件缺一不可：index.html、xlsx.full.min.js、core.js、app.js、data/exam.xlsx。缺任何一个页面都无法正常工作。

### 更新代码版本时

- 覆盖上传 `index.html`、`core.js`、`app.js`（`xlsx.full.min.js` 与 `data/` 一般不用动）
- 上传后等 Pages 部署约 1 分钟，Ctrl+F5 验证

### 故障速查

| 现象 | 原因与处理 |
| --- | --- |
| 卡在「正在加载考试数据…」 | 多为 core.js / app.js 缺失（404）。用 GitHub API 核对：浏览器打开 `https://api.github.com/repos/<用户名>/<仓库名>/contents/` 看真实文件列表 |
| 提示 XLSX is not defined | xlsx.full.min.js 缺失或 index.html 引用了外部 CDN。确认仓库根有 xlsx.full.min.js，index.html 引用 `src="xlsx.full.min.js"` |
| 「HTTP 404」中文提示 | data/exam.xlsx 缺失或路径不对（必须在 data/ 目录下，文件名必须是 exam.xlsx） |
| 页面显示旧数据 | 浏览器缓存，Ctrl+F5 强刷 |
| 想确认线上文件是否最新 | `curl -s -o /dev/null -w "%{http_code}" <线上文件地址>` 看是否 200；对比文件大小是否与本地一致 |

### 数据加载机制（技术说明）

- 页面打开后自动 `fetch('data/exam.xlsx')` 并在浏览器本地解析，无任何服务器参与
- 加载失败自动重试 3 次（间隔 300ms / 900ms），仍失败则展示「手动选择本地文件」备用入口
- 注意：仓库是 Public 时，exam.xlsx 任何人都可下载；如需隐藏名单请改用私有部署方案
