## 使用说明（写给所有访问这个项目的人）

这是一个**免安装、免登录、打开即用**的考试查询网页：输入姓名，立即生成你的个人考试看板——每场考试的日期、星期、时间、考场、时长、倒计时一目了然。全部计算在**你自己的浏览器本地**完成，姓名不会被上传或记录。

### 怎么用（三步）

1. 打开网页，等待出现「✅ 考试数据已自动加载」（数据由管理员统一放在仓库里，无需自己传文件）
2. 在姓名框**输入你的姓名**——支持只输入一部分：边打边出候选名单，点自己的名字即可
3. 看板立即生成。每张考试卡片可以**点击看详情**（监考老师、同场考生、年级班级）

### 功能一览

| 功能 | 说明 |
| --- | --- |
| 模糊搜索 | 写「王」列出一切含王的名字（含「李王昱」「张王成」）；只记得几个字也能乱序命中（「虎王」→「王小虎」）；前缀 > 同字 > 包含三级排序，最多列 60 个候选 |
| 考试详情 | 点击任意卡片：监考老师（几位、姓名）、同场考生名单（**点击同学名字可直接查 TA**）、年级 / 班级 / 考场 / 起止时间；日期被自动修正过的场次会标注原值 |
| 倒计时 | 距离下一场考试还有几天 / 几小时 / 几分钟，带进度条 |
| 进行中标记 | 今天的考试日期行高亮；正在进行的考试显示「● 进行中」呼吸标记与预计剩余分钟 |
| 打印 / 存 PDF | A4 排版，适合贴在桌上 |
| 复制为文本 | 一键复制全部安排，发给同学或家人 |
| 导出日历 (.ics) | 导入手机 / 电脑日历，每场考试自动提前 30 分钟提醒 |
| 记住姓名 | 上次查询的姓名自动记住（仅存在你本机浏览器，清缓存即清除） |
| 弹窗体验 | 详情弹窗由浏览器原生 `<dialog>` 实现：永远屏幕居中，点 ✕ / 遮罩 / Esc 均可关闭 |

### 常见问题

| 问题 | 说明 |
| --- | --- |
| 查不到自己？ | 先试试只输入名字的一部分。若候选名单里也没有，说明监考表里没有这个名字（可能有空格或写法差异，请找管理员核对原表） |
| 提示「存在同名」？ | 看卡片上的年级 / 班级 / 考场，确认是哪一位的考试 |
| 顶部出现黄色警告？ | 解析器发现原表某处格式异常（如不存在的日期 `2.30`、月份越界 `13.5`）。看板的承诺是**绝不静默猜一个错的结果**——警告里写明了行号和原因，请按提示人工核对 |
| 卡片上出现「日期已修正」标记？ | Excel 会把 `11.10` 的尾零吞成 `11.1`，看板按考试日期连续规律自动恢复，并在顶部列出「原值 → 修正值」清单供复核 |
| 页面卡在「正在加载考试数据」？ | 用 Ctrl+F5 强制刷新（GitHub Pages 有约 1–10 分钟更新延迟，刚上传的新文件需要等一等）；仍不行说明仓库文件不全，可对照文件列表核查 |
| 隐私安全吗？ | 查询全部在浏览器本地完成，姓名不会被记录或上传；但仓库为 Public 时 exam.xlsx 本身任何人可下载 |

## 更新文件（写给项目维护者）

### 每学期更新考试数据（唯一要做的常规动作）

1. 打开本仓库 → `data/` 文件夹
2. 把新的监考表**改名为 `exam.xlsx`**，覆盖上传（Add file → Upload files → 拖入 → Commit）
3. 完成。访客下次打开页面就是新数据（自己看不到变化时按 Ctrl+F5 强制刷新缓存）

> 其他 4 个文件（`index.html`、`app.js`、`core.js`、`xlsx.full.min.js`）**永远不需要动**——它们是程序本体，与考试数据无关。**五个文件缺一不可**，页面打开时会自动自检并在缺文件时直接告诉你缺什么。

### 更新程序版本（仅当维护者发新版本时）

1. 从维护者处拿到新的构建产物（`index.html` / `app.js` / `core.js`，有时还有 `README.md`）
2. 在仓库根目录逐个覆盖上传同名文件
3. 上传后在 GitHub 文件页**核对文件大小**与维护者给出的一致（防止上传失败或版本延迟造成「线上表现不对」的假象），再 Ctrl+F5 验证

### 故障速查

| 现象 | 处理 |
| --- | --- |
| 页面显示「页面自检发现问题」 | 按页面提示补传缺失的文件（通常是五文件之一被误删） |
| 更新后表现和预期不符 | 先 Ctrl+F5；再等 5–10 分钟（GitHub Pages 部署延迟）；最后核对线上文件大小是否与本地一致 |
| 数据加载失败提示 | 检查 `data/exam.xlsx` 是否存在且未损坏（下载下来能否正常打开） |

## 数据加载机制
- 页面打开后自动 fetch data/exam.xlsx 并在浏览器本地解析，无任何服务器参与
- 若加载失败（文件未上传/格式损坏），页面会提示并自动展示「手动选择本地文件」备用入口
- 注意：仓库是 Public 时，exam.xlsx 任何人都可下载；如需隐藏名单请改用私有部署方案
