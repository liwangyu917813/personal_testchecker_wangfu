# 期中考试个人看板

输入姓名，即可查看属于自己的期中考试安排：日期星期、时间、考场、倒计时、进行中标记，支持打印 / 复制 / 导出日历（.ics）。所有解析都在你的浏览器里完成，服务器只提供静态页面。

**👉 访客直接打开网站使用即可：<https://liwangyu917813.github.io/personal_testchecker_wangfu/>**

---

## 🙋 使用说明（访客看这里）

### 查询我的考试

1. 打开网站，等待顶部出现绿色提示「✅ 考试数据已自动加载（N 场考试，N 名学生）」
2. 在「🔎 输入你的姓名」框里输入姓名，点「查询我的考试」
3. 看板会列出你的每一场考试，按时间排序，自动标注：
   - 📅 日期 + 星期（跨年的学期日期也能正确显示年份）
   - ⏰ 时间与时长（倒计时进度条：临近考试越短，颜色越急）
   - 📍 考场
   - ● **进行中** 的考试会呼吸脉冲高亮，并显示预计剩余分钟

### 实用功能

| 功能 | 说明 |
|---|---|
| 🖨 打印 / 存 PDF | 看板下方的「🖨 打印/PDF」按钮，或直接 Ctrl+P（打印样式已优化） |
| 📋 复制为文本 | 一键复制全部安排，方便发到班级群 |
| 📆 导出日历 | 下载 .ics 文件，双击导入 iPhone/Android/电脑日历，考前自动提醒 |
| 🔁 记住姓名 | 上次查过的名字会记住（仅保存在本机浏览器），下次直接出结果 |

### 常见问题

- **提示「未找到××的任何考试记录」**
  先检查姓名是否输错；如果你是借读/跨年级考试，可能确实不在本表里，请联系管理员确认数据版本。
- **提示「存在同名，请核对班级」**
  表里有和你同名的同学，看板已按班级区分，请核对你班级的考场是否吻合。
- **显示「🛠 日期已修正」**
  Excel 会把 11.10 这类日期的尾零吞掉（变成 11.1），看板会根据全表日期连续性自动纠正并透明标注，无需担心。
- **页面显示「⚠️ 在线数据暂时无法加载」**
  说明管理员还没上传数据或文件暂时打不开，可以点「手动选择本地文件」用收到的监考表 Excel 临时查询。
- **数据好像不是最新的？**
  按 **Ctrl+F5**（Mac：Cmd+Shift+R）强制刷新，绕过浏览器缓存。

### 隐私说明

- 查询请求和姓名**不会发送到任何服务器**，全部计算在你的浏览器本地完成
- 本工具不含任何统计/追踪代码，姓名只保存在你自己设备的浏览器里
- 注意：监考表数据文件（exam.xlsx）托管在公开仓库中，技术上任何人都可以下载原始表格；如学校要求名单保密，请联系管理员

## 🛠 运营者指导（管理员看这里）

### 仓库结构（五个文件缺一不可）

```
index.html          网页本体
xlsx.full.min.js    SheetJS 解析库（本地文件，勿删，页面不依赖任何 CDN）
core.js / app.js    页面逻辑（必须与 index.html 同目录）
data/exam.xlsx      考试数据（每学期覆盖上传这一份）
README.md           本说明
```

> ⚠️ 上传时容易漏文件：拖入后确认文件列表里出现了全部 5 个文件再点 Commit。缺任何一个都会白屏或报错（页面会用中文提示缺什么）。

### 首次部署（纯网页操作，无需 git）

1. GitHub 新建一个 **Public** 仓库
2. Add file → Upload files，把上面 5 个文件全部上传 → Commit changes
3. Settings → Pages → Branch 选 `main`（或 `master`）→ Save
4. 约 1 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

### 📅 每学期更新数据（运营者唯一要做的动作）

1. 拿到新学期的监考表 Excel（.xlsx）
2. 把文件**改名为 `exam.xlsx`**
3. 打开仓库 → `data/` 文件夹 → Add file → Upload files → 上传覆盖 → Commit
4. 完成。访客下次打开页面就是新数据；已打开的页面按 Ctrl+F5 刷新

> 为什么要改名：页面固定读取 `data/exam.xlsx` 这一个路径，改名后无需改任何代码。
> 建议同时核对：新表打开后顶部统计的「N 场考试」与实际场次数是否一致；页面顶部如有「⚠️ 有 N 行数据格式异常」或「脱离考试日期连续段」的黄色警告，说明表格里有需要人工核对的行，请对照原表检查。

### 故障排查

| 现象 | 原因与处理 |
|---|---|
| 一直显示「正在加载考试数据…」 | 通常是 5 个文件中有漏传/被删。逐个检查线上文件能否打开（如 `https://<用户名>.github.io/<仓库名>/core.js` 能显示内容才算在） |
| 「XLSX is not defined」 | `xlsx.full.min.js` 缺失或没传到根目录 |
| 数据不更新 | 确认新文件确实叫 `exam.xlsx` 且在 `data/` 目录下；再 Ctrl+F5 强刷 |
| Pages 打不开（404） | 检查 Settings → Pages 是否已开启且分支正确；首次部署有 1-2 分钟延迟 |

**排障利器**：浏览器直接访问 `https://api.github.com/repos/<用户名>/<仓库名>/contents/` 可以看到仓库的真实文件列表（无需登录），用来确认上传是否真的成功。

### 数据加载机制（技术细节）

- 页面打开后自动 `fetch data/exam.xlsx`（带 no-cache 策略），在浏览器本地解析，无任何服务器参与
- 加载失败（文件未上传/格式损坏）时，页面会中文提示并自动展示「手动选择本地文件」备用入口
- 解析引擎支持各种脏格式：`11.9`/`11月10日`/`Nov 9`/`周三11.9` 等日期写法、`800-930`/`下午2:00-4:00` 等时间写法、表头出现在前 30 行任意位置、同名检测、重复行去重等（详见源码仓库的使用说明.md）
- 注意：Public 仓库的 exam.xlsx 任何人都可下载；如需隐藏名单请改用私有部署方案
