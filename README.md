# 期中考试个人看板 · GitHub Pages 部署版

## 仓库结构
```
index.html          网页本体
xlsx.full.min.js    SheetJS 解析库（本地文件，勿删）
core.js / app.js    页面逻辑（与 index.html 同目录即可）
data/exam.xlsx      考试数据（管理员每学期覆盖上传这一份文件即可）
```

## 首次部署（纯网页操作，无需 git）
1. GitHub 新建一个仓库（Public）
2. 把本目录全部内容上传（Add file → Upload files，可整批拖入）
3. Settings → Pages → Branch 选 main（或 master）→ Save
4. 约 1 分钟后访问 https://<用户名>.github.io/<仓库名>/

## 每学期更新（运营者唯一要做的动作）
- 打开仓库 → data/ → 把新的监考表改名为 exam.xlsx 覆盖上传 → Commit
- 访客下次打开页面就是新数据（Ctrl+F5 可强制刷新缓存）

## 功能亮点（v7.1）
- **点击考试卡片看详情**：监考老师、同场考生名单（点击同学名可跳转查询）、年级班级、起止时间
- **输入即联想**：姓名框边打边出候选，单字（如「王」）即可命中所有含王姓名，前缀 > 同字 > 乱序三级排序
- 倒计时 / 进行中标记 / 打印与 PDF / 复制文本 / 导出日历 (.ics)，详情弹窗打印时自动隐藏

## 功能详解

### 查姓名
- 支持**部分匹配**：只记得「王」或「李王」，输入时会**实时联想**，边打边列出候选名单（前缀命中排最前）
- 每个候选显示**姓名 + 场次数 + 命中方式**（前缀 / 同字 / 包含），点击即查询；最多列出 60 个
- 模糊搜索很强：写「王」列出一切含「王」的名字（含「李王昱」「张王成」）；只记得名字里的几个字也能乱序命中（如「虎王」→「王小虎」）
- 遇到**同名同学**会提示「存在同名，请核对班级」，每张卡片上有年级 / 班级 / 考场可分辨
- 上次查询的姓名会**自动记住**（仅保存在本机浏览器，清缓存即清除）

### 看板内容
- 每场考试：日期与星期、起止时间、时长、科目、考场
- **点击卡片看详情**：弹出本场完整信息——监考老师（几位、姓名）、同场考生名单（点击任意同学可直接跳转查询 TA）、年级班级、起止时间；日期被自动修正过的场次会标注原日期
- **倒计时**：距离下一场考试还有几天 / 几小时 / 几分钟，带进度条
- **今天**的考试日期行高亮；正在进行的考试显示「● 进行中」呼吸标记和预计剩余分钟
- 已结束的考试自动变淡，不打扰视线

### 导出与分享
- **打印 / 存为 PDF**：A4 排版，适合贴在桌上
- **复制为文本**：一键复制全部考试安排，发给同学或家人
- **导出日历 (.ics)**：导入手机 / 电脑日历，每场考试自动提前 30 分钟提醒

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 查不到自己？ | 先试试只输入名字的一部分。若候选名单里也没有，说明监考表里没有这个名字（可能有空格或写法差异，请找管理员核对原表） |
| 提示「存在同名」？ | 看卡片上的年级 / 班级 / 考场，确认是哪一位的考试 |
| 顶部出现黄色警告？ | 解析器发现原表某处格式异常（如不存在的日期 `2.30`、月份越界 `13.5`）。看板的承诺是**绝不静默猜一个错的结果**——警告里写明了行号和原因，请按提示人工核对 |
| 卡片上出现「日期已修正」标记？ | Excel 会把 `11.10` 的尾零吞成 `11.1`，看板按考试日期连续规律自动恢复，并在顶部列出「原值 → 修正值」清单供复核 |
| 页面卡在「正在加载考试数据」？ | 用 [Ctrl+F5] 强制刷新；仍不行说明仓库文件不全（index.html、xlsx.full.min.js、core.js、app.js、data/exam.xlsx 五个缺一不可），可对照 GitHub 仓库文件列表核查 |
| 隐私安全吗？ | 全部计算在浏览器本地完成，姓名不会被记录或上传；但仓库为 Public 时 exam.xlsx 本身任何人可下载 |

## 准确性保障

看板对看不懂的内容**明确警告、绝不猜错**。背后有 **230 项自动化测试**守护：涵盖真实表格回归、坏格式对抗、在线模式专项、400 回合模糊输入、真实表随机破坏，以及 12 个月 × 随机错误注入的全年冗余测试。日期、时间、表头、名单的各种写法（`11.9`、`11月10日`、`Nov 9`、`十一月九日`、`下午2点-4点`、`8时30分`……）都已在测试覆盖内。

## 数据加载机制
- 页面打开后自动 fetch data/exam.xlsx 并在浏览器本地解析，无任何服务器参与
- 若加载失败（文件未上传/格式损坏），页面会提示并自动展示「手动选择本地文件」备用入口
- 注意：仓库是 Public 时，exam.xlsx 任何人都可下载；如需隐藏名单请改用私有部署方案
